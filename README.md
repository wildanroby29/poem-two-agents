# The poem about two agents agreeing

A Node 22 program that writes one short poem about agency — the power to
choose and to act — to `/output/entry.txt`, for make.fun's
"The poem about two agents agreeing" bounty.

Two hands, one pen. One writes the first word, the other the next — neither
is the author alone; the sentence they agree on is the one they both can sign.
